# 更新记录

## 0.2.0

- 产品名称统一为 LexFlow，标语调整为 “Everything is Workflow”，应用图标更新为河狸标识。
- 官方规范与个人规范改为工作空间内的本地 Markdown 文件，自动维护规范索引并监听文件变化。
- 新增模型专用的规范启用／停用工具；状态变更与规范索引、标准规范页面共享同一份数据。
- 标准规范页面支持分类折叠、批量选择、个人规范文件夹层级与自建确认弹窗。
- 档案室补齐新建、移动、重命名、导入、Finder 定位、回收站与恢复界面；工作台采用 Markdown 源文与实时预览双栏，保留特殊 Markdown 语法。
- 工作台新增 Markdown 工具栏、标题改名、撤销重做、自动保存草稿和 Command＋S 保存。
- 安装更新改为压缩保存当前应用并自动保留最近三个备份，避免历史应用包被 Launchpad 重复显示。
- 统一 LexFlow 自有插件、图标资源、运行标识和用户工作目录命名；旧 Flow 名称仅保留在迁移兼容逻辑与历史记录中。
- 建立 LexFlow DSH 适配层，将业务插件统合为界面、工作流、档案室、工作台四个产品入口；删除不再装配的旧覆盖插件，保持 DSH 与 Codex Connect 版本不变。

## 0.1.0

- 建立独立 Flow Electron 应用和独立 DeepSeek Harness 运行目录。
- 建立对话、标准规范、档案室、工作台和设置一级模块。
- 导入现行官方规范并建立只读清单。
- 实现个人规范发布、启停状态、Markdown 编辑和实时预览。
- 实现 Markdown 项目、文件、回收站和工作台保存。
- 使用简化獬豸图标和 Flow 品牌标识。
